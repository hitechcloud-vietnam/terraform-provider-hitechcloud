# hitechcloud_affiliate_adv_voucher (Resource)

Manages an advanced-affiliate discount voucher
(`POST /api/affiliates_adv/{client_id}/vouchers/{plan_id}`,
`DELETE /api/affiliates_adv/{client_id}/vouchers/{voucher_id}`).

Vouchers cannot be edited after creation: changing any attribute forces a
replacement.

## Example Usage

```terraform
resource "hitechcloud_affiliate_adv_voucher" "summer" {
  client_id = "100"
  plan_id   = "1"
  discount = "10"
  max_usage = "100"
}
```

## Schema

### Required

- `client_id` (String) Affiliate client ID. Changing this forces a new resource.
- `plan_id` (String) Commission plan ID the voucher belongs to. Changing this
  forces a new resource.

### Optional

- `audience` (String) Target audience of the voucher.
- `code` (String) Voucher code; generated by the API when omitted. Changing this
  forces a new resource.
- `cycle` (String) Billing cycle the discount applies to.
- `discount` (String) Discount value of the voucher.
- `expires` (String) Expiry date of the voucher.
- `max_usage` (String) Maximum number of redemptions.

### Read-Only

- `id` (String) Voucher identifier returned by the API.
- `status` (String) Current voucher status reported by the API.
- `used_count` (String) Number of times the voucher has been redeemed.

## Import

Import is supported using the composite ID `client_id/voucher_id`:

```shell
terraform import hitechcloud_affiliate_adv_voucher.summer 100/voucher-1
```
